# Simple Game Engine

A simple 2D/3D engine with:

- Physics
- UI
- Multiplayer
- Advanced, pixel perfect shape rendering
- Post processing effects
- Much more

## Documentation

A book about SGE, which serves as the main documentation, can be found [here](https://sge.lilyrl.com/).

Automatically generated reference documentation for SGE can be found [here](https://docs.rs/sge/latest/sge/).
Most of the content is in the `prelude` module.

There is an example for every feature in the engine, start with `simple.rs`.

## Installation

Add the following to your `Cargo.toml`.

``` toml
[dependencies]
# stable
sge = { version = "*" }
# latest
sge = { git = "https://github.com/LilyRL/sge" }
```
